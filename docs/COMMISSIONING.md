# Commissioning — введення в експлуатацію (Phase 10, SPEC 205)

Виконувати по порядку. Сирену підключати ТІЛЬКИ на останньому кроці.

## 1. Полярність реле (без навантаження!)

1. Підключіть модуль реле до D5/GND/VIN (5 В) або 3V3 — за специфікацією модуля.
2. Web UI → Реле → «Тест реле» (або серіал: `test`). Слухайте клацання.
3. Якщо реле клацає ПІД ЧАС тесту — полярність правильна.
   Якщо реле увімкнене постійно, а на тесті вимикається — переключіть
   «Полярність» на ACTIVE LOW і повторіть.
4. Перевірте серіал-лог: `[RELAY] ON` → `[RELAY] OFF` рівно на тривалість тесту.

## 2. Поведінка при старті

1. `restart` у серіалі (або кнопка RST). Реле НЕ повинно клацнути при буті.
2. Повторіть з вимкненням/увімкненням живлення.
3. Прошийте плату заново — реле не повинно клацати і під час прошивки.
   Якщо клацає — додайте зовнішній підтягуючий резистор (HARDWARE.md).

## 3. Safety timeout

1. Web UI → Реле → «Макс. безперервно УВІМК» → тимчасово 3000 мс.
2. Серіал: `sim air_raid full`, у профілі START поставте on_ms=10000.
3. Реле має вимкнутися через 3 с (`[LOG] RELAY_SAFETY_TRIP`).
4. Поверніть налаштування.

## 4. Кнопки

- MUTE короткий тиск під час патерна → тиша миттєво, LED показує mute-патерн.
- MUTE довгий (2с+) → snooze.
- TEST утримання 2 с → короткий пульс реле.

## 5. LED (коли є MCP23017)

Перевірте обидва RGB, кожен колір окремо, спільний анод/катод у конфізі.

## 6. Тестове навантаження

Замість сирени — LED-стрічка 12 В або лампа. Проженіть повний цикл:
`sim air_raid full` → START-патерн → `sim air_raid none` ×2 → END-патерн.

## 7. Сирена

Тільки після всіх кроків вище. Перший тест — «Тест реле» (короткий),
навушники зняти, вуха берегти.
