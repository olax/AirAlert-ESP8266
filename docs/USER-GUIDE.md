# Посібник користувача AirAlert

Це інструкція для того, хто користується пристроєм. Технічні деталі — в
інших файлах `docs/`.

## Що робить пристрій

Кожні 15 секунд питає alerts.in.ua про тривоги у **ваших** локаціях і:
- вмикає сирену через реле патерном (початок / нагадування / кінець тривоги);
- світить індикатором тривоги, поки загроза активна;
- показує все у веб-інтерфейсі та веде журнал подій.

Працює сам: без телефона, сервера чи інтернет-сервісів окрім alerts.in.ua.

## Перше налаштування

1. Увімкніть пристрій. Він створить Wi-Fi мережу **AirAlert-XXXX**
   (пароль — на наліпці або в серіал-консолі, рядок `[WIFI] PROVISIONING`).
2. Підключіться до неї телефоном — відкриється сторінка налаштування
   (якщо ні — відкрийте http://192.168.4.1/setup).
3. Введіть: домашній Wi-Fi і пароль, API-токен
   (безкоштовно: https://alerts.in.ua/api-request), пароль адміністратора.
4. Пристрій перезавантажиться і з'явиться у вашій мережі. Адресу покаже
   роутер або серіал (`[WEB] http://…`).

## Веб-інтерфейс

`http://<адреса-пристрою>/`, пароль адміністратора.

| Вкладка | Що там |
|---|---|
| Стан | поточні тривоги, тривалість, кнопки Заглушити / Реле ВИМК |
| Локації | вибір областей/районів зі списку (можна кілька) |
| Сигнали | патерни сирени для кожного типу загрози, пріоритети |
| Реле | полярність, safety-ліміт, тест реле, індикація, часткові тривоги |
| API | заміна токена, інтервал опитування |
| OTA | оновлення прошивки файлом або з URL |
| Журнал | історія подій (тривоги, збої, дії) |
| Система | діагностика: пам'ять, Wi-Fi, аптайм |

## Індикація

**Вбудований світлодіод плати (синій):**

| Світить | Значення |
|---|---|
| постійно | все працює: Wi-Fi + час + токен + свіжі дані API |
| повільно блимає | є проблема (немає інтернету / API мовчить) — гляньте журнал |
| швидко блимає | режим налаштування або OTA |

**Індикатор тривоги (зовнішній, на D0):** горить = у ваших локаціях
активна тривога. Часткова тривога (частина області) — повільне блимання;
заглушена — короткі спалахи. У режимі «стійкий сигнал» (для реле з
лампою) — просто горить без блимань.

## Сирена

- **Початок тривоги**: 3 гудки по 3 секунди (налаштовується).
- **Кінець**: 2 гудки по 1 секунді.
- **Ескалація** (часткова стала повною): знову початковий сигнал.
- Захист: реле фізично не може бути ввімкнене довше 30 с поспіль,
  що б не сталося.

## Заглушення (MUTE)

- Кнопка MUTE або Web UI → «Заглушити»: сирена замовкає **миттєво**,
  але тривога лишається на індикаторі й у Web UI.
- Коротке натискання = тиша до кінця цієї тривоги; довге (2с) = на 15 хв.
- **Новий тип загрози** (напр. хімічна після повітряної) пролунає
  попри заглушення — це навмисно.

## Якщо щось не так

| Ситуація | Поведінка пристрою | Що робити |
|---|---|---|
| Зник інтернет/API | Індикатор і Web UI показують «дані застарілі»; остання відома тривога НЕ скидається | нічого — відновиться сам |
| Зник Wi-Fi | пробує перепідключитись; через 2 хв додатково підніме мережу AirAlert-XXXX | за потреби зайти на 192.168.4.1 і поправити Wi-Fi |
| Пропав пароль адміністратора | — | серіал-консоль: `setpass новий-пароль` (див. docs/SERIAL.md) |
| Пристрій «мовчить» на реальну тривогу | перевірте вкладку Локації і журнал | можливо, тривога не у ваших локаціях |
| Реле вимкнулось само посеред сигналу | запис RELAY_SAFETY_TRIP у журналі | перевірити патерни: on × повтори > ліміту |

## Оновлення прошивки

Web UI → OTA → вибрати `firmware.bin` → завантажити. Налаштування, Wi-Fi
і токен зберігаються. Під час оновлення сирена примусово вимкнена.
Не вимикайте живлення до перезавантаження.

## Безпека

- Пристрій розрахований на домашню мережу — не відкривайте його порт 80
  в інтернет.
- Токен API зберігається лише в пристрої і ніде не показується.
- Той, хто фізично забере плату, зможе прочитати з неї токен і пароль
  Wi-Fi — це обмеження заліза (ESP8266 не має захищеного сховища).
