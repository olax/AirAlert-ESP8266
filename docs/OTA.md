# OTA-оновлення

## Через Web UI (основний шлях)

OTA → вибрати `firmware.bin` (збірка `pio run -e nodemcuv2_prod`,
файл `.pio/build/nodemcuv2_prod/firmware.bin`) → «Завантажити прошивку».
Перед прошивкою пристрій примусово вимикає реле і зупиняє чергу сигналів
(Invariant 8). Після успіху — автоматичний ребут; конфіг, Wi-Fi, токен і
локації зберігаються (вони на LittleFS, OTA чіпає тільки код).

## Через URL

OTA → HTTPS URL + SHA-256 образу (обчислити: `sha256sum firmware.bin`).
Пристрій сам завантажує образ, рахує SHA-256 потоково і відхиляє
невідповідність до активації. Хости: GitHub Releases, будь-який HTTPS
за DigiCert/USERTrust/Let's Encrypt/GTS.

## Обмеження (SPEC 105)

- ESP8266 не має A/B-розділів: невдале завантаження НОВОЇ прошивки після
  успішного запису = цеглина до перепрошивки по кабелю. Тому:
  - тестуйте нову версію по кабелю до OTA-розкатки;
  - тримайте `stock-backup` і USB-кабель під рукою.
- Захисти, які Є: перевірка магії/розміру образу, SHA-256 (URL),
  watchdog, збереження конфігу між версіями (schema migration).

## Бюджет розміру

Розкладка 4M2M: staging = 2 МБ − sketch. Лімітує лінкований IROM ≈ 1019 КБ.
CI відсікає prod-образ > 900 КБ. Поточний розмір ~520 КБ.
